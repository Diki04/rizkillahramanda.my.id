# Design System & Style Guide

## Philosophy: Anti-AI Slop
- **No blurry gradient orbs**: Crisp borders with subtle alpha transparencies (`border-slate-800/80`).
- **Tactile feedback**: Custom spotlight border illumination tracking cursor coordinates.
- **Monochrome & Deep Navy**: Base background `#070A12`, card surface `#0B1120`, electric cyan accents `#38BDF8`.
- **Typography**: Inter (modern sans) paired with JetBrains Mono (precision technical metrics).

## Color Tokens
- `dark-bg`: `#070A12`
- `dark-card`: `#0B1120`
- `dark-border`: `#1E293B`
- `accent-blue`: `#38BDF8`
- `accent-cyan`: `#22D3EE`
