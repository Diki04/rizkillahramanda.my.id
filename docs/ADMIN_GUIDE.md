# Admin Portal User Guide

## Accessing the Portal
- Navigate to: `/admin` (or press `Ctrl+K` / `Cmd+K` and select "Admin Portal").
- Passcode: Configured via `ADMIN_SECRET_KEY` in your environment variables (`.env.local`).

## Adding a New Project
1. Select the **Projects** tab.
2. Fill out:
   - Project Title
   - Description
   - Category (Fullstack, Web, Machine Learning, Mobile)
   - Tech Stack (comma separated)
   - Live URL & GitHub URL
3. Click **Add Project**.

## Adding a New Certificate
1. Select the **Certificates** tab.
2. Fill out:
   - Certificate Title
   - Issuer (Dicoding, Coursera, Kampus Merdeka, etc.)
   - Date
   - Credential URL
3. Click **Add Certificate**.
