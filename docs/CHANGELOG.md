# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-10-07
### Added
- Modular monolith Next.js 14 App Router architecture with pnpm.
- Deep Navy monochrome anti-slop design system.
- SpotlightCard with custom mouse cursor illumination.
- 60fps geometric canvas constellation background.
- Multi-language (i18n) support for Indonesian and English.
- Realtime developer metrics dashboard (GitHub API, Wakatime, Monkeytype, Codewars).
- Projects gallery with category filtering and modal inspection.
- Supabase PostgreSQL integration with resilient fallback data provider.
- Passcode-protected administrative management portal (`/admin`).
- Keyboard shortcut command palette (`Ctrl+K` / `Cmd+K`).
- Interactive CLI terminal easter egg in 404 page.
- Comprehensive unit test suites and architectural documentation.
